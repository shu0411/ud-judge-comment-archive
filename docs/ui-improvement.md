# UI改修指示書

## 背景・目的

現状のヘッダーが縦に長く、特にモバイル表示でスクロール領域を圧迫している。
また目次がヘッダー下のコンテンツ内に混在しており、使いづらい。
以下の改修でヘッダーをコンパクトにまとめ、目次をドロワー化する。

---

## 改修内容

### 1. Header（共通）

**現状**: タイトル・説明文・ボタン類が縦に並び、ヘッダーが縦に長い  
**改修後**: 1行の固定ヘッダーに変更

レイアウト:

```txt
┌──────────────────────────────────────────┐
│ [☰]  UNIDOL 審査員コメントまとめ  [⤢][⤡] │
└──────────────────────────────────────────┘
```

- 左端: ハンバーガーアイコンボタン（**モバイルのみ表示**、PCでは非表示）
- 中央: サイトタイトル（`UNIDOL 審査員コメントまとめ`）
- 右端: 全展開・全折りたたみのアイコンボタン2つ（PC・モバイル共通で常時表示）
- ヘッダーは `position: fixed` で画面上部に固定
- 現状ヘッダー内にある説明文・非公式表記はヘッダーから切り出し、ページ最上部のコンテンツ領域（ヘッダー直下）に移動する

#### 全展開・全折りたたみのアイコン案

lucide-react の以下アイコンを使用:

- 全展開: `ChevronsDownUp` または `Expand`
- 全折りたたみ: `ChevronsUpDown` または `Shrink`

ツールチップ（`title` 属性）で「全て展開」「全て折りたたむ」を表示すること。

---

### 2. サイドバー（PCのみ、`md` ブレークポイント以上）

**現状**: 常時表示で開閉不可  
**改修後**: 開閉可能なサイドバーに変更

#### 開いた状態

```txt
┌────────┬──────────────────────┐
│ 目次[〈]│                      │
│        │  コンテンツ          │
│ 2026S  │                      │
│ 2025W  │                      │
└────────┴──────────────────────┘
```

- サイドバー上部に閉じるボタン `[〈]`（左向き矢印）を表示

#### 閉じた状態

```txt
┌──┬──────────────────────────┐
│〉│                          │
│  │  コンテンツ（ワイド）    │
└──┴──────────────────────────┘
```

- サイドバーを幅約40pxの細いバーに縮小（完全非表示にはしない）
- 細いバー内に展開ボタン `[〉]`（右向き矢印）のみ表示
- 開閉は `transition` によるアニメーション付き（幅のスライド）

---

### 3. 目次ドロワー（モバイルのみ、`md` ブレークポイント未満）

**現状**: ヘッダー下にインラインで目次が表示されている  
**改修後**: ハンバーガーメニューからスライドインするドロワーに変更

#### 挙動

- ヘッダー左端のハンバーガーボタン（☰）をタップするとドロワーが左からスライドイン
- ドロワー外の領域に半透明のオーバーレイを表示
- オーバーレイのタップ、またはドロワー内の閉じるボタン（✕）でドロワーを閉じる
- 目次の項目をタップしたら該当セクションへスクロールし、ドロワーを閉じる

#### ドロワーのレイアウト

```txt
┌────────────────┬──────────────┐
│ 目次        [✕]│ オーバーレイ │
│                │（半透明暗幕）│
│ UNIDOL 2026S   │              │
│ UNIDOL 2025W   │              │
│ ...            │              │
└────────────────┴──────────────┘
```

- ドロワー幅は画面幅の約75%（最大280px程度）
- ドロワーは `position: fixed` でヘッダーの高さ分だけ下から表示
- 現状ヘッダー内にある目次セクション（`≡ 目次` の部分）は廃止する

---

## 変更しないもの

- `TournamentSection`・`EventSection` の開閉ロジック
- ツイート埋め込み（`TweetEmbed`）の実装
- ダーク/ライトテーマの切替（`prefers-color-scheme`）
- データ構造（`tournaments.json`）
